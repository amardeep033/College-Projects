# College Projects

This repository is a container for academic and personal college project work. Each project directory maintains its own implementation details, setup steps, and project-specific documentation in its local `README.md`.

## How To Use This Repository

- Start at the project folder you want to work on.
- Read that project's own `README.md` for setup, dependencies, and usage.
- Keep shared repository-level files in the root only when they apply across projects.

## Projects

### Military Canteen Management System

- Path: `military-canteen-management-system/`
- Stack: PHP, MySQL, HTML, CSS
- Purpose: mini-project for managing inventory, employees, customers, and sales in a military canteen

## Repository Layout

- `military-canteen-management-system/`: project source code and assets
- `military-canteen-management-system/REPORT/`: academic report material

## Conventions

- Add project-specific documentation inside the relevant project folder.
- Keep the root `README.md` limited to repository navigation and high-level guidance.
- Use the root `.gitignore` for editor, OS, and general workspace artifacts.

## Notes

- This root README is intentionally brief and should not duplicate project-level setup instructions.
- As more projects are added, list them in the `Projects` section with a short description.
